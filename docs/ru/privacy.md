# Приватность и разрешения

[English](../privacy.md) · **Русский** · [К документации](../../README.ru.md)

По умолчанию расширение обрабатывает данные локально. Оно использует соединение чата и данные эфира, которые уже загрузила страница Twitch. Библиотека подсказок входит в сборку. Для работы расширения не нужны сервер проекта, аналитика или внешние шрифты.

- Разрешение `storage` нужно для настроек и истории. Фоновый обработчик упорядочивает записи от разных вкладок.
- Текст сообщений и буфер аудита находятся в памяти вкладки. При экспорте выбранные данные, включая публичные сообщения и ID авторов, записываются в скачанный JSON.
- В локальной истории хранятся интервалы наблюдения, вовлечённость, замеры, события, ID участников групп и отпечатки фраз. Хранилище ограничено по размеру и сохраняет до 20 эфиров канала. Историю можно очистить в настройках Chat X-Ray в чате Twitch. Уже скачанные файлы хранятся отдельно.
- При включении проверки возраста (`accountAgeLookup`) расширение запрашивает дату создания подходящих аккаунтов у `gql.twitch.tv`. Это необязательный запрос к неофициальному API Twitch. По умолчанию функция выключена. Запрос отправляется без cookie.

## Передача сообщений внутри страницы

Скрипт в контексте страницы читает `window.WebSocket` и передаёт сообщения изолированному скрипту расширения. При загрузке страницы создаётся случайный токен для этой передачи. Обработчик отбрасывает сообщения без подходящего токена. В манифесте Firefox указано `data_collection_permissions: none`.
