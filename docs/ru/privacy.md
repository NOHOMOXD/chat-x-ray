# Приватность

[English](../privacy.md) · **Русский** · [К документации](../../README.ru.md)

Всё работает на Вашем компьютере.

- **Одно разрешение — `storage`.** Ни аккаунтов, ни аналитики, ни телеметрии, ни запросов на обновление. Библиотека подсказок входит в сборку.
- **Хранится:** настройки и до 20 последних эфиров по каждому просмотренному каналу (покрытие, темп чата, замеры, счётчики событий, ID аккаунтов из подозрительных групп). Кнопка «Очистить историю эфиров» это удаляет.
- **Не хранится:** сообщения чата живут только в памяти вкладки, если Вы сами не выгрузите сессию. Скачанный JSON расширение обратно не читает.
- **Обмен внутри страницы:** расширение передаёт сообщения между своими скриптами внутри страницы, с защитой случайным токеном на каждую загрузку, чтобы другие скрипты не могли подмешать поддельный чат.

## Единственный необязательный запрос

**Проверка возраста аккаунта** по умолчанию выключена. Если включить, расширение спрашивает `gql.twitch.tv` — адрес, которым пользуется сам twitch.tv, — дату регистрации у аккаунтов, набравших хотя бы 30 баллов или ещё способных дойти до Вашего порога. Запросы идут пачками, с ограничением частоты, без cookie; ответы живут только в памяти вкладки. Выключите настройку — и сетевого трафика не останется.

В манифесте Firefox указано, что данные не собираются; это соответствует описанному.
