# Установка и обновления

[English](../distribution.md) · **Русский** · [К документации](../../README.ru.md)

## Что в релизе

| Файл | Для кого |
| --- | --- |
| `chat-x-ray-vX.Y.Z-chrome-opera.zip` | Chrome, Edge, Opera |
| `chat-x-ray-vX.Y.Z-firefox.zip` | Firefox (временная установка) |
| `*.xpi` | Firefox, подписанный — только если настроены секреты AMO |
| `chat-x-ray-vX.Y.Z-source.zip` | Сборка из исходников |
| `SHA256SUMS.txt` | Контрольные суммы |

Для установки распакуйте архив Вашего браузера (с окончанием `-chrome-opera.zip` или `-firefox.zip`). В корне распакованной папки находится `manifest.json`. Дальнейшие шаги описаны в [README](../../README.ru.md#установка).

Проверка загрузки, по желанию:

```bash
shasum -a 256 -c SHA256SUMS.txt   # macOS
sha256sum -c SHA256SUMS.txt       # Linux
```

## Обновление

Замените файлы в **той же** папке и нажмите «Обновить» на странице расширений — иначе браузер поставит его как новое. Временные дополнения Firefox загружаются заново после каждого перезапуска. Перед удалением выгрузите то, что нужно сохранить: локальное хранилище вместе с историей эфиров может исчезнуть вместе с расширением.

## Постоянная установка в Firefox

Обычный Firefox требует подпись Mozilla для постоянной установки. Её можно получить для непубличного дополнения: отправить пакет на проверку Mozilla с вариантом self-distribution и установить полученный подписанный `.xpi`. Покупать собственный сертификат не требуется. Каждую новую версию нужно подписывать заново; без настроенного адреса обновлений её придётся устанавливать вручную. Подробности: [подпись дополнений](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/) и [самостоятельное распространение](https://extensionworkshop.com/documentation/publish/self-distribution/).

Команда `npm run package` создаёт неподписанный Firefox ZIP для временной загрузки. Релизный workflow может дополнительно получить подписанный `.xpi` при настроенных секретах AMO; отсутствие секретов не делает ZIP подписанным.
