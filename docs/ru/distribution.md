# Установка и выпуск релизов

[English](../distribution.md) · **Русский** · [К документации](../../README.ru.md)

В GitHub Release предусмотрены архив Chromium для Chrome и Opera, архив Firefox, исходники и файл SHA256SUMS.txt. Для проверки скачанных файлов выполни `shasum -a 256 -c SHA256SUMS.txt` на macOS или `sha256sum -c SHA256SUMS.txt` на Linux в каталоге с файлами выпуска.

| Браузер | Установка |
| --- | --- |
| Chrome | Распакуй архив Chromium. Открой `chrome://extensions`, включи режим разработчика и выбери «Загрузить распакованное расширение». |
| Opera | Используй тот же архив. Открой `opera://extensions`, включи режим разработчика и выбери распакованную папку. |
| Firefox | Установи подписанный XPI, если он есть в выпуске. Для временной установки распакуй Firefox ZIP и укажи его manifest.json в разделе временных дополнений на `about:debugging#/runtime/this-firefox`. Временное дополнение действует до перезапуска браузера. |
| Safari на Mac (локальная разработка) | В каталоге исходников на Mac выполни `npm ci` и `npm run package:safari`. Распакуй полученный проект Safari, открой его в Xcode, выбери схему приложения macOS и запусти её. Разреши неподписанные расширения в настройках разработчика Safari, включи Chat X-Ray в настройках расширений и предоставь доступ к Twitch. |

Для самостоятельной сборки нужны полный Xcode и Safari 18+. В Safari 18.4+ для временной проверки можно выполнить `npm run build:safari` и выбрать `dist/safari` через **Add Temporary Extension** в настройках разработчика. [Руководство SponsorBlock](https://github.com/ajayyy/SponsorBlock/wiki/Safari#build-it-yourself-free) · [Документация Apple](https://developer.apple.com/documentation/safariservices/distributing-your-safari-web-extension)

При переходе с локальной версии 1.5.0 в Chromium замени сборку в прежнем каталоге и перезагрузи расширение. В Firefox сохрани тот же профиль и идентификатор Gecko. Перед удалением старой установки экспортируй нужный аудит: удаление расширения может очистить его хранилище.

## Автоматический выпуск

1. Из чистой копии репозитория выполни `npm ci` и `npm run package`. На Mac с выбранным полным Xcode при необходимости выполни `npm run package:safari`. В исходный ZIP попадают отслеживаемые Git файлы из HEAD. Сырые записи и локальные отчёты оставляй вне Git.
2. После отправки ветки запусти workflow **Release** вручную для репетиции. Он выполняет проверки, пересобирает исходный ZIP в чистом каталоге и запускает браузерные тесты Chromium и Firefox параллельно на Linux. Скачай артефакт и проверь состав и контрольные суммы.
3. Для публикации отправь тег, совпадающий со всеми тремя компонентами версии, например `v1.0.0`. Workflow создаст GitHub Release с примечаниями. Секреты `AMO_JWT_ISSUER` и `AMO_JWT_SECRET` включают дополнительную подпись Mozilla. Для обновления существующих установок Firefox сохрани идентификатор Gecko.
