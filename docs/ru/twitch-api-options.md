# Какие данные доступны через Twitch API

[English](../twitch-api-options.md) · **Русский** · [К документации](../../README.ru.md)

Расширению не нужны ни аккаунт, ни токен, ни сервер. Здесь — почему и что могли бы добавить API.

| Сведения | Helix | Ограничение |
| --- | --- | --- |
| Дата регистрации | `GET /helix/users?login=` | Нужен OAuth-токен |
| Онлайн и начало эфира | `GET /helix/streams?user_login=` | Токен, лимиты |
| Подписки и фолловеры | `/helix/subscriptions`, `/helix/channels/followers` | Только свой канал |
| Участники чата | `GET /helix/chat/chatters` | Нужны права модератора |
| Кто смотрит видео | — | Twitch это не раскрывает |

Client Secret нельзя встроить в расширение, так что Helix означал бы сервер — а это ломает работу без сервера. Необязательная проверка возраста вместо этого использует публичный GQL, которым пользуется сам twitch.tv: без пользовательского токена и cookie, пачками и с ограничением частоты. Адрес нестабилен, поэтому функция необязательная.
