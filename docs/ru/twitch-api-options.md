# Какие данные доступны через Twitch API

[English](../twitch-api-options.md) · **Русский** · [К документации](../../README.ru.md)

Основные функции используют чат и счётчик зрителей открытой страницы. Для точного определения возраста аккаунта предусмотрен отдельный запрос по желанию пользователя.

| Сведения | Официальный Helix API | Условия и ограничения |
| --- | --- | --- |
| Дата регистрации | `GET /helix/users?login=` | Поле created_at, нужен токен OAuth |
| Онлайн и начало эфира | `GET /helix/streams?user_login=` | Поля viewer_count и started_at, есть лимиты запросов |
| Подписки и фолловеры | `/helix/subscriptions`, `/helix/channels/followers` | Для подробных списков нужны соответствующие права на канале |
| Участники чата | `GET /helix/chat/chatters` | Нужны права владельца или модератора канала |
| Аккаунты, смотрящие видео | — | Публичный список зрителей плеера недоступен |

Секрет приложения нельзя безопасно включить в распространяемое расширение. Для настройки проверки возраста проект использует неофициальный GQL веб-клиента Twitch. Запрос `user(login){createdAt}` с публичным Client-ID позволяет получить дату регистрации без пользовательского токена.

Запросы группируются и ограничиваются по частоте и количеству на загрузку страницы. По умолчанию интервал составляет минимум 1,2 секунды. Ответы сохраняются в памяти вкладки, cookie не отправляются. При ошибке возраст остаётся неизвестным. Интерфейс GQL может измениться без предупреждения.

Подтверждённая дата используется для признака возраста меньше 90 суток. Близость ID оценивается отдельно. Публичный счётчик и чат позволяют сравнивать активность эфиров, но этих данных недостаточно для независимой проверки числа живых зрителей.
