# Chat X-Ray для Twitch

[English](README.md) · **Русский**

Расширение отмечает подозрительные аккаунты в открытом чате Twitch и оценивает аудиторию эфира по активности в чате. Анализ работает в Вашем браузере. Поддерживаются Chrome, Edge, Opera и Firefox. Интерфейс доступен на русском и английском.

Safari пока не поддерживается.

> Проект независим от Twitch Interactive, Inc.

## Что видно

- **Бейджи.** `BOT 65` отмечает подозрительного автора, `35?` показывает баллы без поведенческого признака, `ID` — участника плотной группы ID. Наведите курсор, чтобы увидеть причины.
- **Фильтр чата.** Похожие сообщения, вставки и потоки символов за последние 15 минут можно приглушать или скрывать.
- **Оценка аудитории.** Рядом со счётчиком Twitch появляется примерная оценка числа зрителей. Официальный счётчик остаётся на месте.
- **Активность чата.** С первого сообщения виден счётчик чаттерсов. Когда данных достаточно, появляется оценка зрителей.
- **Красные предупреждения.** Счётчик показывает волну, низкую активность чата и аномалии онлайна. Плашка чата отдельно отмечает волну и высокую долю подозрительных авторов.
- **Выгрузка сессии.** По желанию — JSON со всем, что расширение заметило за эфир.

## Быстрый старт

1. Установите расширение — шаги ниже.
2. После первого сообщения аудитории рядом с онлайном появится число чаттерсов в скобках, например (33). В подсказке видны процент сбора, сообщения и события эфира.
3. Диапазон оценки появится после одной минуты наблюдения, пяти сообщений аудитории и двух чаттерсов после фильтра.

После короткого перерыва (до двух минут) расширение продолжает расчёт по сохранённому окну того же эфира. Время перерыва исключается. При более позднем возвращении рядом с онлайном виден возраст последней совместимой оценки, пока собираются свежие данные.

## Установка

1. Откройте **[Releases](https://github.com/NOHOMOXD/chat-x-ray/releases)** и скачайте последний `chat-x-ray-vX.Y.Z-chrome-opera.zip` (Chrome, Edge, Opera) или `chat-x-ray-vX.Y.Z-firefox.zip` (Firefox).
2. Распакуйте архив в папку, где будет храниться расширение.
3. Загрузите расширение:
   ```text
   Chrome / Edge / Opera   chrome://extensions → режим разработчика → «Загрузить распакованное» → эта папка
   Firefox 140+            about:debugging#/runtime/this-firefox → «Загрузить временное дополнение» → manifest.json
   ```
   Временное дополнение в Firefox исчезает после перезапуска — используйте подписанный `.xpi`, если он есть в релизе.
4. Откройте любой канал Twitch.


Сборка из исходников — только для разработки: [Разработка](docs/ru/development.md).

## Настройки

В настройках чата Twitch (шестерёнка под чатом) снизу появляется строка **Chat X-Ray Settings**, как у BetterTTV. Ещё есть шестерёнка в заголовке чата и страница параметров самого расширения.

- Что делать с отмеченными аккаунтами: оставить, приглушать или скрывать.
- Что фильтр делает с повторами: приглушать или скрывать.
- Порог (по умолчанию **30**), плашка чата, счётчик зрителей, запись сессии, необязательная проверка возраста, язык.

## Ваши данные

Одно разрешение — `storage`. По умолчанию ничего никуда не отправляется. Единственное исключение — необязательная проверка возраста, которую Вы включаете сами: [Приватность](docs/ru/privacy.md).
