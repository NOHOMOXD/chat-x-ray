# Chat X-Ray для Twitch

[English](README.md) · **Русский**

Расширение отмечает подозрительные сообщения в открытом чате Twitch и показывает рядом со счётчиком зрителей оценку аудитории по активности чата. Работает локально. Интерфейс доступен на русском и английском. Проект независим от Twitch.

## Что видно на стриме

- Бейдж `BOT 65` перед ником показывает баллы подозрительности. Наведи на него курсор, чтобы увидеть вклад каждого признака.
- Фильтр R9K сравнивает сообщения в скользящем окне и может приглушать или скрывать повторы.
- Рядом с официальным онлайном сначала появляется процент готовности, затем диапазон оценки. Расчёт предполагает, что за десять минут пишут 8–12,5% зрителей.
- Плашка чата показывает темп, авторов и волны. Поповер онлайна показывает изменения счётчика и сравнение вовлечённости с предыдущими наблюдавшимися эфирами канала.
- В настройках можно включить запись сессии и скачать JSON для разбора.

## Установка

Скачай архив исходников или клонируй репозиторий. Из корня проекта выполни:

```bash
npm ci
npm run build:all
```

В Chrome, Edge и Opera открой страницу расширений, включи режим разработчика и загрузи папку `dist/chrome` как распакованное расширение. В Firefox 140+ открой `about:debugging#/runtime/this-firefox`, выбери загрузку временного дополнения и укажи `dist/firefox/manifest.json`. Для Safari на Mac и установки из архивов релиза см. [инструкцию по установке](docs/ru/distribution.md).

## Настройки

Открой шестерёнку в заголовке чата или пункт Chat X-Ray в настройках самого чата Twitch. Здесь можно выбрать язык, изменить порог (по умолчанию 30 баллов), включить проверку даты регистрации, настроить бейджи, R9K, счётчик зрителей, запись и экспорт.
